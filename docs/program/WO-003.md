# WO-003 -- Safe update with health check and automatic rollback

Why: updates were done by ad-hoc scripts with no way back. One command must update Eva, and put the old
version back by itself if the new one cannot start or does not stay up.
Branch: `wo-003-safe-update`
Files you may change: tools/update.py (new), update.bat (new, repo root), eva_app/housekeeping.py (heartbeat
only), tools/update_main.bat (DELETE it), run_checks.py (ADD one check), README.md (the "updating" lines),
docs/program/reports/WO-003.md.

## Design (fixed)
- Heartbeat: while Eva runs, a timer (every 10 s, in eva_app/housekeeping.py) writes ~/.eva/heartbeat.json
  = {"pid", "commit" (git rev-parse --short HEAD read once at start), "time" (epoch seconds)}.
- tools/update.py, pure functions + a thin main(), all git/process calls go through an injectable `run`
  so the check can fake them. Sequence:
  1. refuse if `git status --porcelain` shows changes to tracked files (print them; exit 2);
  2. old = current commit; stop Eva (the process whose command line contains main.py, never itself);
  3. `git fetch origin main`, `git merge --ff-only FETCH_HEAD`; if that fails -> restart Eva on old, exit 3;
  4. run `python main.py --selftest`; if it fails -> `git reset --hard <old>`, start Eva, exit 4;
  5. start Eva (run.bat, minimised); wait up to 90 s for heartbeat.json with the NEW commit and a time newer
     than the start; if it does not come -> stop Eva, `git reset --hard <old>`, start Eva, exit 5;
  6. append one line to ~/.eva/updates.log: time, old -> new, result. Print the same line.
  Never move, rename or delete any file. Never touch untracked files.
- update.bat: activates the venv and runs tools\update.py, then `pause`.

## Steps
1. Branch. Add the heartbeat (step: start Eva, confirm the file changes every 10 s, paste two readings).
2. Write tools/update.py and update.bat. Delete tools/update_main.bat.
3. Add ONE check to run_checks.py with a fake `run`: (a) dirty tree -> refuses, nothing else called;
   (b) selftest fails -> reset to old and Eva started; (c) no heartbeat -> reset to old and Eva started;
   (d) healthy -> no reset, log line written (use a temp dir for the log and heartbeat).
4. Live proof on the PC, with the Director's permission (takes ~5 min): on a throwaway branch add
   `import module_that_does_not_exist` to coder.py, push it as `origin/wo-003-broken`, and run update.py
   with an option `--ref wo-003-broken`. Expect exit 4, Eva running again on the old commit. Paste the
   output and the updates.log line. Delete the throwaway branch.
5. Full checks, report, PR.

## Acceptance
- Step 4 output shows the automatic rollback and Eva alive on the old commit (heartbeat reading).
- The check covers the four cases; full checks pass; tools/update_main.bat is gone; only listed files changed.
