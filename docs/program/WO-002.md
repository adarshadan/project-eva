# WO-002 -- `python main.py --selftest`

Why: on 2026-11-14 an update left Eva unable to start ("No module named 'coder'") and nothing noticed. A
build must be able to prove it can start, without opening her window or using the network.
Branch: `wo-002-selftest`
Files you may change: main.py, eva_app/startup.py, selftest.py (new), run_checks.py (ADD one check only),
docs/program/reports/WO-002.md.

## Design (fixed -- do not change it)
- New module selftest.py with `run() -> list[str]` returning problems (empty list = healthy). It must:
  a. import every module in eva_app.startup's module list (reuse that list; do not copy it);
  b. import core.toolset and check every registered tool has an implementation or is in the
     bound-at-startup set (reuse what startup_self_test already checks);
  c. check web/avatar_3d.html and web/assets/character.glb exist and are non-empty;
  d. check config.MODEL_ID is a non-empty string and `providers.parse(config.MODEL_ID)` does not raise;
  e. check ~/.eva is writable (create and delete a temp file).
  It must NOT create a QApplication, open a window, start the microphone, or make a network request.
- main.py: if "--selftest" is in sys.argv, call selftest.run() BEFORE anything else in main(), print each
  problem as `SELFTEST FAIL: <text>`, print `SELFTEST OK` if none, and exit with code 1 or 0.

## Steps
1. Branch from latest main. Read eva_app/startup.py::startup_self_test and main.py::main.
2. Write selftest.py (a-e above). Run `venv\Scripts\python.exe main.py --selftest`; expect `SELFTEST OK`, exit 0.
3. Prove it catches the real failure: rename coder.py to coder.py.bak, run again, expect a
   `SELFTEST FAIL` line naming coder and exit code 1 (`echo %ERRORLEVEL%`). Rename it back. Paste both outputs.
4. Add ONE check to run_checks.py (register it in the final list): selftest.run() returns [] on the
   repository, and returns a problem naming the module when one module name in the list cannot be imported
   (inject a fake module name through a parameter, do not rename files in the check).
5. Run the full run_checks.py and motion tests. Report, commit, push, PR.

## Acceptance
- Outputs of steps 2 and 3 in the report (OK/exit 0, FAIL naming coder/exit 1).
- `--selftest` finishes in under 15 s and no window appears. Full checks: `All checks passed.`
- Only the listed files changed.
